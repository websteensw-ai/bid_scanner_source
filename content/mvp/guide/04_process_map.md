# 6단계 학습 지도

| 단계 | 중심 질문 | 산출물 |
|---|---|---|
| 0 문제 제시와 풀이 준비 | 무엇을 풀어야 하고, 제시문에서 무엇을 확인해야 하나요? | 풀이 준비 메모 |
| 1 제시문 읽기 | (가)와 (나)는 무엇을 말하나요? | 제시문 요지 |
| 2 설명 기준 | 두 관점은 무엇으로 판단하나요? | 설명 기준·공통 축 |
| 3 (가)로 설명 | (가)로 보면 (다)는? | (가) 관점 설명 |
| 4 (나)로 설명·비교 | (나)로 보면? 둘은 무엇이 다른가요? | (나) 설명·비교 |
| 5 개요 | 어떤 순서로 쓸까요? | 세 문단 개요 |
| 6 독립 작성 | 혼자 써 볼까요? | 제출본·자기검증 |
| 6-1 평가·첨삭 | 무엇을 유지하고 고칠까요? | 최종본 |

학습 중에도 화면 위 진행 막대에서 이 지도를 다시 볼 수 있어요.
