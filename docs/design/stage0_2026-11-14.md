# 제0단계 심층 설계와 시뮬레이션 — 출제 문제 제시와 풀이 준비

> 설계자 전달본 (2026년 11월 14일, 전체 문장 수록본). 기존 MVP 설계 가이드의 0단계 설계를 **대체**한다.
> 구현 위치: `content/mvp/stage_cards.yaml`(0단계 카드), `content/mvp/packs/BASIC-Q1/pack.yaml`(0단계 하위 목표·오류·보충 사다리·예시 장면), `src/mvp/engine.py`(복수 항목 동시 확인·판정·연결 기록), `web/templates/_mvp_dialogue.html`.

## 요지 (구현 기준)

- **중심 질문**: 나는 지금 어떤 문제를 풀어야 하며, 그것을 풀기 위해 제시문에서 무엇을 확인해야 하는가?
- **세 가지 준비**: ① 하고 싶은 이야기보다 요구한 일 먼저 ② 찾을 내용과 근거 의식 ③ 모르는 부분 인정, 원문 확인하며 판단
- ‘출제자의 의도 파악’ = 지시어·설명 대상·활용 제시문·작성 조건을 근거로 요구된 수행을 파악하는 것 (숨은 정답 추측이 아님)

### 0단계와 1단계의 경계

| 구분 | 제0단계 | 제1단계 |
|---|---|---|
| 중심 과제 | 무엇을 해야 하며 어떻게 읽을지 준비 | 실제로 읽고 무엇을 이해했는지 설명 |
| 논제 이해 | 지시어·대상·조건을 잠정적으로 구분 | 독해 결과와 연결하여 요구를 정확히 재구성 |
| 제시문 접근 | 찾아야 할 내용과 근거의 종류 설정 | 핵심 내용과 관계를 실제 원문에 근거하여 파악 |
| 주요 산출물 | 풀이 준비 메모 | 독해 결과와 문제 재구성 |
| 요구하지 않을 것 | 두 관점의 정확한 차이, 완성된 설명 | 완성된 논증과 최종 답안 |

### 첫 화면
「논술학습 6단계 기본과정 출제 문제 1」, 제시문 (가)~(라) 전체, 논제와 작성 조건, 총 100점·시간 100분을 원문 그대로 먼저 제시한다. 요약·비교표를 먼저 보여 주지 않는다. 이어서 튜터의 최초 안내문.

### 문제 접근 요령 (Ⅳ)
1. 주제어보다 지시어를 먼저 2. 대상과 관점을 구별 3. 여러 요구를 빠짐없이 구분 4. 핵심 단어뿐 아니라 관계를 읽기 5. 알고 있는 지식과 제시문 근거를 구분 6. 모르는 것을 표시하고 성급한 결론을 피하기

### 준비 상태 확인 (Ⅴ) — 긴 설문이 아니라, 자연스러운 설명에서 확인되지 않은 부분만 추가 질문
| 확인 항목 | 수행 증거 | 부족할 때의 질문 |
|---|---|---|
| 요구한 활동 파악 | 설명·비교 등 해야 할 일을 말함 | 논제에서 행동을 요구하는 표현을 찾아보십시오. |
| 대상과 관점 구별 | 무엇을 어떤 관점으로 설명할지 구별함 | 이 문장에서 설명받는 대상은 무엇입니까? |
| 요구의 완결성 | 일부 과업만 하고 끝내지 않음을 인식함 | ‘두 설명’은 앞의 어떤 활동을 가리킵니까? |
| 근거 중심 읽기 | 원문에서 관점과 사례의 연결 근거를 찾겠다고 말함 | 그 설명이 맞는지 무엇으로 확인하겠습니까? |
| 조건 확인 | 700자 이내 등 작성 조건을 확인함 | 작성 조건에서 지켜야 할 사항을 찾아보십시오. |
| 불확실성 인식 | 모르는 내용과 확인할 부분을 구별함 | 지금 확정하지 않고 더 읽어야 할 부분은 무엇입니까? |

“이해했습니다”, “잘 읽겠습니다”, “핵심을 찾겠습니다”만으로는 준비가 확인되지 않는다.

### 완료 판정 (Ⅷ)
핵심 기준: ① 주요 요구를 자기 말로 ② 설명 대상과 활용 관점 구별 ③ 관점·사례·근거의 연결을 확인해야 함 ④ 작성 조건 확인. 두 관점의 정확한 차이는 요구하지 않는다.
판정: 준비 확인 / 지원 후 준비 확인 / 추가 지원 필요 / 미확인. 내용 독해의 어려움만으로 0단계를 반복시키지 않고 1단계로 전달한다.

### 기록과 1단계 연결 (Ⅸ)
최초 과업 이해, 오해·누락한 요구, 제공한 질문과 발판, 수정된 준비 메모, 1단계에서 확인할 불확실한 부분을 보존한다. 1단계는 “무엇을 해야 합니까?”를 다시 묻지 않고 준비 메모를 불러와 시작한다.

### 실전 준비 질문 (Ⅹ)
무엇을 해야 하는가? / 무엇을 대상으로, 어떤 자료를 사용해야 하는가? / 제시문에서 무엇과 그 근거를 찾아야 하는가? / 빠뜨리면 안 되는 요구와 조건은 무엇인가?

### 주 시뮬레이션 (Ⅵ, 장면 1~8)과 보충 경로 (Ⅶ)
`pack.yaml` 의 `exemplars`(장면)와 `stage_ladders["0"]`(빈 틀 제공 등)에 옮겨 담았다. 원문은 설계자 전달본을 따른다.
